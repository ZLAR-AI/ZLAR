# ZLAR's first design

This folder holds the checkpoint for MCP tool calls. It is part of ZLAR's first design: a checkpoint that
sits next to the AI and checks its actions before they go through.

It works on the paths routed through it, and it taught the lesson that shaped
everything since: the protection belongs with the thing being protected, not next
to the AI. It's kept for reference and for its tests. It isn't where ZLAR is
heading.

**Start in [`cyan/`](../cyan/),** the force field, after the
[README](../README.md). AI readers: see [AGENTS.md](../AGENTS.md).
