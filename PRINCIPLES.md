# ZLAR's Principles

ZLAR puts a force field around the things that matter. Whether a force field
protects people or hems them in comes down to one question: who holds the keys,
and for how long? ZLAR is built around a few lines it doesn't cross.

## No master key

No single party holds everyone's keys, including us. Every house keeps its own. A
master key is a single point of failure.

## The key belongs to whoever lives with the consequence

The farmer holds the key to the farm, not the company that sold the tractor and
not the one that wrote the software. Authority starts with the person who has to
live with what happens.

## Keys don't last forever

A key works for a set time and then stops unless someone renews it. Nobody has to
remember to take it back. Nothing is permanent by default.

## The rules about keys are behind the force field too

Changing who holds which keys is itself something that needs the right keys. No
quiet edits, and no back door for whoever runs the system. A lock you can
reprogram from outside isn't a lock.

## No answer means no

If nobody answers, nothing happens.

## Thought is free

ZLAR never looks at what a superintelligence, or a person, is thinking. It only
stands at the moment something becomes real.

## Anyone can check, and show

Each house keeps its own signed record. Anyone can check it without trusting
ZLAR, and show it to whoever needs to see it.

---

## Where each stands today

These are commitments about how ZLAR is built. Some are already in the code; the
rest are on the list of what isn't built yet in the [README](README.md).

| Line | Today |
|---|---|
| No master key | A design commitment. Today's demonstrations each run one house with a single founder-held key. |
| The key belongs to whoever lives with the consequence | A design commitment. |
| Keys don't last forever | Built in the reference code: every key must carry an expiry, and an expired key stops with no cancel message. Smooth renewal on a real system is not built yet. |
| The rules about keys are behind the force field | Partly built: rules are signed, and pushes to this repository from the founder's computer need a hardware key. The full version is on the work list. |
| No answer means no | Built: unanswered requests expire and nothing happens. |
| Thought is free | Built into the design: nothing in ZLAR reads what a superintelligence is thinking. |
| Anyone can check, and show | Built for Demo 1: its records can be checked offline without ZLAR. |
